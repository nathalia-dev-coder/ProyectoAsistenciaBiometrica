👁️ Sistema Biométrico Básico con IA
📖 Descripción del Proyecto
Este proyecto es un sistema de autenticación biométrica impulsado por Inteligencia Artificial. Está diseñado para capturar, analizar y verificar la identidad de los usuarios mediante el reconocimiento de patrones biométricos (como el reconocimiento facial) en tiempo real.

El sistema utiliza modelos de aprendizaje automático para extraer características únicas de cada usuario y compararlas con una base de datos segura, ofreciendo una alternativa moderna y sin contraseñas para el control de acceso.

🚀 Funcionalidades Principales
📝 Registro Biométrico (Enrollment): Captura inicial de los datos biométricos del usuario para crear un modelo o "hash" único que se almacena de forma segura.

🔐 Autenticación en Tiempo Real: Verificación rápida comparando la entrada de la cámara en vivo con los perfiles registrados.

🤖 Detección de "Liveness" (Prueba de Vida): (Opcional/Básico) Algoritmos integrados para detectar que el sujeto frente a la cámara es una persona real y no una fotografía.

📊 Panel de Registro: Interfaz sencilla para gestionar los usuarios registrados y ver el historial de accesos.
